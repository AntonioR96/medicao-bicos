# Medição de Bicos

App web instalável para a medição da vazão dos bicos de pulverizadores, de uso interno.

**Acesso restrito:** o conteúdo do app é cifrado e só abre com o usuário e a senha fornecidos aos supervisores.

**Abrir no celular:** https://antonior96.github.io/medicao-bicos/

No Android (Chrome), use o menu ⋮ → "Instalar app" ou "Adicionar à tela inicial". No iPhone (Safari), use
Compartilhar → "Adicionar à Tela de Início". Depois da primeira entrada, funciona sem sinal e não pede a senha de novo.

As medições ficam só no celular de quem usa; nenhum dado é enviado. O PDF é gerado no aparelho com
[jsPDF](https://github.com/parallax/jsPDF) 2.5.1 (licença MIT, em `vendor/`).
